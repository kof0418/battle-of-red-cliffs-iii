# 赤旌 · Three Kingdoms Battle

v0.3 原創三國街機橫向動作原型。Phaser 3 + TypeScript + Vite，960 × 540 像素畫面。角色、場景與音效均由程式原創繪製／合成，沒有使用《吞食天地 II》的圖像、音樂、角色造型或地圖。

## 遊玩

Enter 或點擊遊戲開始；WASD／方向鍵上下左右走位；J 攻擊（連按觸發三段連擊）；K／空白鍵跳躍；L 閃身（短暫無敵、0.95 秒冷卻）；P 暫停；R 重新開始。手機畫面提供觸控按鈕。畫面下方另有暫停／繼續及重試按鈕；暫停或結束後也能點擊遊戲畫面繼續。敗陣時若尚有續關次數，點擊畫面或 Enter 會續關；R／「重開」始終重開整個戰役。切離視窗會暫停，回來按 P 或點擊繼續。

主角沈烈以長刀攻擊前方同一深度的敵人；第三段傷害與擊退更強。跳到高處可避開地面攻擊。敵人頭上的金色提示表示即將出招，可上下走位閃避。清場回復 35 點生命並向右前進，通過兩陣後挑戰守關將軍。擊倒第一關最後一陣所有敵人後進入轉場；按 Enter 或點擊前往第二關「夜渡蘆江」。第二關同樣三陣，擊倒水寨統領「蒼鷲」及所有守軍後完成戰役，生命歸零可重試。

敵兵：步卒（均衡）、游騎（快速）、重甲（耐打）、鐵獄守將（高血量、長距離重擊）。每關三波敵人、生命條、命中停頓、震動、擊退、合成音效、計分、勝敗與重開皆已實作。最高得分會保存在此瀏覽器的 localStorage；沒有關卡存檔或多人連線。停用儲存仍可遊玩。

## 開發與建置

建議 Node.js 22.18+ 與 npm。使用鎖定檔可重現安裝。

```sh
npm ci
npm run dev
# http://127.0.0.1:5173
npm test
npm run build
npm run preview
```

`dist/` 是完整靜態網站，正式執行不需要 Node.js、資料庫或外部素材服務。也可執行 `python3 -m http.server 8080 --directory dist`。請透過 HTTP 開啟，不要雙擊 HTML。相對資源路徑支援子目錄部署。

## Docker / Nginx

```sh
docker compose up --build -d
# http://localhost:8080
docker compose down
```

也可把 `dist/` 放到任何靜態網站伺服器。參考 `docker/nginx.conf`；正式對外服務的 HTTPS 由部署端反向代理管理。

## Tauri 2 桌面架構

`src-tauri/` 提供 Rust 入口、Tauri 2 設定、開發與建置掛鉤。共用 Web 核心，無需複製遊戲邏輯。

```sh
npm run desktop:dev
npm run desktop:build
```

先安裝 Rust stable 與目標平台工具鏈。Windows 需 MSVC C++ Build Tools、Windows SDK 與 WebView2；macOS 需 Xcode command-line tools。Windows 安裝程式請在 Windows 建置，macOS app 請在 macOS 建置。離線 Windows 發行還需決定 WebView2 離線安裝策略；正式發行前補齊圖示、簽章及公證。桌面部分仍為封裝骨架，未宣稱已產出 EXE／APP。

## 原始碼

- `src/main.ts`：Phaser 場景、輸入事件緩衝、特效、HUD、最高分與操作介面。
- `src/combat.ts`：可獨立測試的戰鬥模擬、角色數值、AI、Boss 招式與波次。
- `src/actor.ts`：快取繪圖物件、12 fps 姿態動畫、三段刀光。
- `src/background.ts`：夕照關隘與月夜水寨兩套原創程序化像素場景。
- `src/levels.ts`：關卡、劇情、Boss 名稱與敵人編隊資料。
- `src/style.css`：街機外框、響應式版面與觸控操作。
- `tests/*.test.ts`：19 項規則與流程測試，包括正常輸入兩關通關模擬。

此版以程序化像素繪圖製作每秒 12 格姿態動畫，不使用外部圖像。後續可製作更細緻的原創精靈圖、音樂與更多關卡。

## v0.2 刀光再起

- 三段刀法具有不同出手時間、姿勢與傷害；連擊輸入可預先緩衝，命中停頓不吞按鍵。
- 新增傷害跳字、像素火花、連擊數、閃身冷卻條與結算最高連擊。
- 敵人錯開站位，最多兩名同時蓄力；普通敵人受擊會中斷出招。
- 鐵獄使用範圍震地與直線突進，地面橙色區域預告招式，半血進入怒勢並加快動作。Boss 蓄力不會被普通攻擊中斷。
- 清完當前敵人才能離開戰區；清場補血只觸發一次。玩家死亡優先於同時清場。
- 最高分僅保存在當前瀏覽器；Site、本機與桌面版各自獨立。

Node 測試執行器使用內建 TypeScript stripping，執行 `npm test` 建議 Node.js 22.18+。Web 正式輸出仍只需靜態 HTTP 伺服器。

## v0.3 關山夜渡

本版完整戰役為兩關、六陣、21 名敵人，最後完成評級結算。第一關「暮色關隘」保留鐵獄，第二關「夜渡蘆江」使用月夜、水面、渡船、蘆葦及木棧道場景。新 Boss 蒼鷲使用雙向橫掃、突進與震地，半血加速。橫掃可跳躍或閃身躲避。

- 每陣一只補給木箱，打破後掉落 +40 氣血藥包；擊倒重甲掉落 +25 藥包。
- 走近並落地自動拾取；滿血不消耗藥包，補血不超過上限。進入下一陣會清除上一陣未拾取補給。
- 前兩陣清場各回復 35 氣血；前往第二關時回復全血。
- 每次出征兩次續關：重新生成當前一陣敵人與補給，回復全血及短暫無敵；分數與擊倒數退回該陣開始時，最高連擊保留。
- 續關用完仍可用 R 或重開按鈕從第一關重新挑戰。續關是當次遊玩內的狀態，重新整理頁面不保留關卡進度。
- 通關評級：未續關且剩餘氣血至少 80 為 S；至多續關一次為 A；使用兩次為 B。最高得分保存在 `red-banner-best-v03`，與舊版記錄分開。

### 本機畫面驗證

`npm run dev` 時可使用 `?preview=river`、`?preview=intermission`、`?preview=continue`，分別預置第二關、轉場與續關畫面，方便測試。這些設定只在 Vite 開發模式生效，正式 build 會移除分支；正式網址無跳關功能。
