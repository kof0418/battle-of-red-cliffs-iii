# 赤壁之戰三 · v2.2.2

原創三國街機橫向動作遊戲。Phaser 3 + TypeScript + Vite；960 × 540 像素畫面。六名武將、五關戰役、30 陣、185 名敵人。美術與音樂由程式原創製作，不使用《吞食天地 II》的受保護素材。

## 遊玩與操作

選擇關羽、張飛、趙雲、黃忠、魏延或呂布後按 Enter／出陣。WASD 或方向鍵移動；J 攻擊；K／空白鍵跳躍；L 衝撞；P／Esc 暫停選單；R 要求返回選將（需確認）。支援標準手把、按鍵重設與觸控按鈕。

- 必殺技：先下、400 毫秒內按上，再於 280 毫秒內新按一次攻擊。無計量表、無獨立必殺鍵。六將各有專屬招式與武器撞擊音效，沒有戰吼或人聲配音。
- 抓取：停止攻擊，走近並推向敵人。抓住後可立即左右＋攻擊方向摔，或跳躍後在空中按攻擊空中摔；原地可打兩下再摔，第三次原地攻擊解除抓取。每次接招限時 2.8 秒；五關 Boss 均可抓取，含滿血及蓄力階段；出招瞬間、倒地、起身保護或抓取冷卻中不可抓；Boss 收招 .18 秒後可抓。
- 補給：加大木箱位於上下牆邊。肉回復 40、包子回復 25，滿血時保留；清陣與跨關不再回血。每次出征兩次續關，從當前一陣重來。
- 暫停：遊玩時以遊戲畫面為主，設定收在暫停選單。切離視窗會暫停，回來後手動繼續。
- 無戰鬥存檔。重新整理、關閉頁面或返回選將需重新出征；音量、按鍵與通關戰績可保留。瀏覽器禁止儲存仍可遊玩。

## 開發與建置

使用 Node.js 22.18+ 與 npm：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run release
```

`dist/` 為可獨立部署的靜態遊戲，不需後端或外部素材服務。可使用 `python3 -m http.server 8080 --directory dist`，或 Web 包內的 `python3 scripts/play.py`。請透過 HTTP 開啟，不要直接雙擊 HTML。

## Docker / Nginx

```sh
docker compose up --build -d
# http://localhost:8080
docker compose down
```

HTTPS 由部署端反向代理管理。設定見 `docker/nginx.conf`。

## 拾取武器

未持有拾取武器時，走近即可裝備。小刀只可投擲一次，直線飛行命中第一名同路線敵人；戰錘、長劍、戰斧不限揮擊次數，累計受傷兩次後脫手消失。無敵期間擋下的攻擊不計次。跨關保留武器狀態，敗陣續關恢復原武器。

## 圓筒與騎乘
每陣牆邊新增一個圓筒，打破後出現兵書（加 1500 分）或召馬銅鑼。拾取銅鑼後一匹馬從右側奔入，靠近可自動上馬；馬匹停留 20 秒。六名武將騎乘時使用原配兵器，黃忠以弓箭遠射；普通攻擊有三段連擊，馬匹移動逐步加速。先按左、400 毫秒內按右，再於 280 毫秒內新按攻擊，可使出由上往下揮刀的穿透刀波，攻擊面向前方多名敵人。按跳躍可下馬；騎乘時衝撞鍵改為馬匹突擊，反方向＋攻擊可回身攻擊。原拾取武器收起保留，下馬後恢復。

騎乘受傷會落馬，同一匹馬第一次落馬後留在原地，第二次落馬才跑走。主動跳躍下馬不計落馬次數，馬匹會原地等待且不會逾時消失；再次騎乘保留落馬次數。換關或敗陣續關會清除場上等待的馬匹。

本版新增呂布（方天畫戟），可用數字 6 選將；必殺「無雙裂陣」，摔技「飛將摔軍」。地面手持拾取武器時同時按攻擊＋跳躍可放下武器，再次拾取會保留受擊次數。騎乘中取得銅鑼改加 1000 分，換到下一關一律恢復步行。黃忠箭矢改為帶箭頭、箭桿及箭羽的飛行動畫。

黃忠箭矢以實際飛行碰撞判定傷害；普通箭命中首個目標即消失，第三箭可穿透。下馬後先離開馬匹再靠近才能重新上馬。

後續已確認規劃見 `ROADMAP.md`，不以修正版取代。

## v1.4.3 戰區與衝撞
L 衝撞可傷害並擊退敵人，一次衝刺對同一目標僅傷害一次。新增高壯拳兵與圓錘胖兵。戰鬥時玩家限制在當前畫面內，仍可左右走位；清場後向右推進，鏡頭不向後捲動。敵人可被擊出兩側畫面並嘗試回場，仍可從版邊攻擊。

 v1.4.4：清場後步行進入下一陣，鏡頭平滑前進再鎖定；左右地面摔距離增加 80%。抓敵起跳時可按左右移動，無方向則垂直跳；空中攻擊會與敵人共同落地重摔，波及附近敵人。全部敵人與 Boss 血量加倍，玩家血量不變。

## v1.4.5 武將動作

六將三段連擊各有獨立姿勢，抓持收起武器並配合雙手接觸與落地收勢。使用原配武器時，跳躍後按攻擊使出下降攻擊，下降接近敵人時命中；每跳一次攻擊，可在空中走位，朝向維持起手方向。黃忠以弓身近身擊打。撿拾武器的攻擊＋跳躍放下、騎馬跳躍下馬與抓敵跳躍重摔依原操作。

本版以 192 項測試及正式 Web 建置驗證。動作與命中修整不代表六將數值已完成整體平衡，後者已於 v1.5.0 配合敵人與 Boss 改版處理。

## v1.5.0 敵人與 Boss

出征前在「設定／操作 → 操作、音效與進階設定」選休閒、標準或挑戰，限制同時出招敵人為 1、2、3 名；各難度戰績分開記錄。戰鬥中不能改難度。

突襲兵繞側、弓槍兵維持距離、盾兵短暫架盾。可用第三段重擊、空中攻擊、必殺技、重武器、衝撞、繞背或抓摔突破盾牌。Boss 於 65%／30% 血量變招，警戒範圍固定，收招時有反擊提示。張飛移動與收招節奏小幅加快。

217 項測試通過；六將以正式兩次續關限制完成標準難度五關自動策略測試。可用 `node --experimental-strip-types scripts/benchmark_balance.ts` 重現比較；測試策略不代表實際玩家通關時間。詳見 RELEASE-1.6.0.md 與 BALANCE-1.6.0.md。


## v1.6.0 關卡節奏與重玩性

五關分別採分隊推進、兩側夾擊、竹林伏兵、重裝壓陣、宮城接力；第 2～5 陣分批抵達，清完當批會在短暫預警後叫出下一批。援軍未到齊前保持鎖定，不提前清陣。每次出征從三種有限組合取樣，續關保持同組配置，Boss 不隨機替換。

第 2、4 陣的上／下牆邊各有一個可擊破機關：弩機發射貫穿箭、水閘熄滅本陣火線、竹索落竹擊倒同一直列敵人、冰柱震退附近敵人、軍旗使守軍失守。機關只啟動一次，不掉回血物；軍旗效果也會短暫影響後到援軍。

每關以時間、受傷、續關、最高 HIT 及機關互動給 S／A／B／C 評價，分別加 5000／3000／1500／500 分，只在結算時加一次。失敗嘗試的時間與傷害仍計入，暫停不計時。戰役完成後顯示五關評級；不新增存檔功能，跨關不回血。

251 項測試與正式 Web 建置通過，包含六將 × 四組配置的標準難度完整五關流程，使用正式兩次續關限制。Mac 重建仍安排於 v1.8.0，Windows 仍延後。


## v1.7.0 手機與手把操作

手機橫向取消底部 140 像素預留列，戰場使用完整可視高度，按鈕改覆蓋在畫面兩側；維持 16:9，不裁掉戰場或拉伸。超寬手機仍可能有左右留邊。安全區與可視視窗大小隨旋轉、瀏覽器工具列及全螢幕變化更新。

方向盤支援八向滑動與中立區，可一指移動、另一指攻擊或跳躍。每根手指分別持有動作，放開其中一指不會誤清掉其他指令。暫停、離開頁面、旋轉及取消觸控會清理輸入。預設動作按鈕約 64～84 像素，可在設定勾「加大橫向觸控按鈕」再放大約 15%；844×390 下為 74→85 像素。

出陣時在支援的觸控瀏覽器嘗試進入原生全螢幕，也可按右上 ⛶。拒絕或不支援時維持可視視窗版面，不阻止遊戲。這不保證所有 iOS／Android 瀏覽器都能隱藏系統工具列。

觸控下上＋新按攻擊容許 650／380 毫秒，允許滑動途中的斜向偏差；手把為 450／300 毫秒，鍵盤維持 400／280 毫秒。各裝置指令序列分開，騎馬左右＋攻擊仍保留，沒有新增單鍵必殺。

設定可自訂標準映射手把的攻擊、跳躍、衝撞按鈕；防止重複配置，保留 Start、Back 與方向鍵。提示依配置更新，搖桿加入啟動／回中不同門檻，避免邊界抖動造成重複方向輸入。

267 項測試通過；另以瀏覽器實際量測 844×390、932×430、740×360、568×320、390×844 版面，驗證加大模式與點按下上攻擊。這些檢查不等同 iOS／Android 實機多點硬體測試或原生全螢幕驗證。Mac App 仍待 v1.8.0 重建。

## v1.8.1 解困與 Xbox 操作

未持拾取武器、站在地面時，攻擊＋跳躍消耗 8 點血，使出周身解困震退；可打斷受擊硬直，短暫無敵，至少保留 1 血，使用獨立解困冷卻（v1.8.2 起）。持拾取武器時仍為丟武器；抓住敵人時維持原抓摔操作。騎乘中／已有馬匹的銅鑼改加 1000 分，不召出第二匹馬。

電腦支援 Xbox USB／藍牙手把的瀏覽器標準映射；連接後先按任意按鈕再放開。左搖桿／十字鍵移動、A 攻擊、B 跳躍、X 衝撞、A＋B 解困（持拾取武器時丟下）、Menu/Start 暫停、View/Back 設定。必殺 ↓↑＋A，騎乘刀波 ←→＋A。動作可在設定改鍵，畫面提示隨設定更新。拔除或更換控制器自動暫停，放開按鍵後再恢復；須由瀏覽器提供 standard 映射。不提供未識別控制器的猜測映射，實體 Xbox 硬體尚未驗證。

## v1.8.2 戰鬥手感與判定

解困改為獨立 1.2 秒冷卻，可中斷步戰必殺及受擊硬直，仍消耗 8 血。解困後至少 .85 秒才可用必殺，避免交替無敵。倒地時不可行動，起身有短暫保護（武將 .35 秒／敵人 .18 秒）。步戰原配武器第三段近戰使普通敵人倒地 .45 秒；Boss 保留既有抗打斷規則。近戰採腳底同路線 ±30 像素，範圍邊界接觸計入。畫面外敵人回場時同步向玩家所在路線靠近，保留兩側擊出與版邊攻擊。

## v1.10.0 抓摔與連段深化

原配武器前兩段輕擊（黃忠為近身弓擊）實際命中後，鬆開攻擊並推向同一名敵人，可在收招後段走近接抓；揮空、第三擊、拾取武器與遠射不啟動收招銜接。跳躍起手不會同時誤抓地面敵人。

方向摔依抓住時的面向區分向前拋摔與過肩背摔，背摔有過肩軌跡及向後收身。各將既有投擲距離保留。普通兵地面摔 .60 秒、重裝兵 .66 秒、Boss .72 秒；重裝與 Boss 抬舉較慢、跳摔較低，落地重摔分別 .38／.42 秒。空中摔仍是武將與敵人共同落地，垂直與左右跳皆可。

地面投擲以整段飛行路徑判定身體碰撞，同一敵人每摔只受一次波及，排除不在路線或高度範圍的敵人。抓打零至兩下後方向摔、第三下原地攻擊鬆手及每次 2.8 秒接招時限維持。

五關 Boss 可在站立、早期蓄力及命中後 .18 秒以上收招時抓取，出招前 .12 秒至出手後 .18 秒為危險區間。血量不限制抓取；釋放／掙脫後 Boss 有 1.8 秒擒拿冷卻。Boss 血條旁顯示當前抓取狀態。

## v1.11.0 馬戰擴充

馬上原攻擊鍵可連續三段（第三段較重、收招較長）；按馬頭反方向＋攻擊朝後出招，馬匹保持朝向。單獨反方向移動會用 .14 秒轉身，行進逐步加速至 290。攻擊期間停步，轉身不瞬間後退。

衝撞鍵 L／Xbox X／觸控「衝」變為馬匹突擊：向馬頭方向快速前進 .32 秒，對途經每名同路線敵人造成一次 38 傷害；冷卻 1.15 秒、不附加無敵。普通攻擊收招中不能開始突擊。跳躍仍下馬，被擊中仍落馬，同一匹馬兩次受擊落馬才離場。

六將馬上顯示各自兵器：關羽長刀、張飛蛇矛、趙雲長槍、黃忠長弓、魏延戰刀、呂布畫戟。黃忠的馬上普通箭以實際飛行判定，第三箭貫穿；左右＋攻擊改射貫穿箭，其他五將保留刀波。

## v2.1.0 連段與解困
原配武器步戰須命中敵人才累進三段；揮空、盾擋與物件不累進。前兩段命中後，收招期間可用下上＋攻擊接必殺，提前輸入最多保留 0.28 秒；第三段不能取消。第三段上＋攻擊向後摔、下＋攻擊向前摔，需同一路線 96 像素內可抓取敵人，否則正常第三段。既有直接抓取與空摔不變。黃忠箭矢實際命中才累進，近身弓擊可銜接。拾取武器、騎乘保留原連段。

解困命中敵人才扣 8 血，命中多人也只扣一次；揮空不扣血，冷卻及收招不變，仍需高於 8 血才能施放。新指令方向與命中確認各玩家獨立，↓↑必殺優先於方向摔；不新增教學彈窗或存檔。

## v2.2.0 六將專屬打法
六將使用固定的原配兵器與專屬招式；騎乘及拾取武器採其獨立規則。

## v2.2.1 關羽與張飛專屬動作
關羽原創組三段為橫江掃、挑月斬、斷岳劈。橫掃寬、上挑收窄、重劈較慢，空摔向後拱身翻摔。張飛原創組為猛虎直刺、回身撞軍、震地砸。直刺集中、回身撞擊展開、第三段踏地爆發，地面摔從更高處舉拋，空摔整圈旋轉。
