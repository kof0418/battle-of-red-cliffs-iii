# 赤旌 · Three Kingdoms Battle

v1.3 原創三國街機橫向動作遊戲。Phaser 3 + TypeScript + Vite，960 × 540 像素畫面。角色、場景、音樂與音效均由程式原創繪製／合成，沒有使用《吞食天地 II》的圖像、音樂、角色造型或地圖。

## 遊玩

Enter 或點擊遊戲開始；WASD／方向鍵上下左右走位；J 攻擊（預設可長按連擊，可在設定關閉）；K／空白鍵跳躍；L 閃身（短暫無敵、0.95 秒冷卻）；P 暫停；Esc 設定／操作；R 返回選將重新開始。手機畫面提供觸控按鈕。畫面下方另有暫停／繼續及重試按鈕；暫停或結束後也能點擊遊戲畫面繼續。敗陣時若尚有續關次數，點擊畫面或 Enter 會續關；R／「重開」會先要求確認，再重開整個戰役。切離視窗會暫停，回來按 P 或點擊繼續。

五名可選武將：關羽、張飛、趙雲、黃忠、魏延，使用原創造型與動作。除黃忠使用弓箭外，其餘武將以近戰攻擊前方同一深度的敵人；第三段傷害與擊退更強。跳到高處可避開地面攻擊，但高度超過 38 時自身攻擊也無法命中地面敵人或木箱；落地有 0.12 秒硬直，中斷未完成的攻擊。敵人頭上的金色提示表示即將出招，可上下走位閃避。清場回復 35 點生命並向右前進，通過兩陣後挑戰守關將軍。擊倒第一關最後一陣所有敵人後進入轉場；按 Enter 或點擊前往第二關「夜渡蘆江」。第二關同樣三陣，擊倒水寨統領「蒼鷲」及所有守軍後完成戰役，生命歸零可重試。

敵兵：步卒（均衡）、游騎（快速）、重甲（耐打）、鐵獄守將（高血量、長距離重擊）。每關三波敵人、生命條、命中停頓、震動、擊退、合成音效、計分、勝敗與重開皆已實作。最高得分會保存在此瀏覽器的 localStorage；v0.4 起支援本機存檔與 JSON 匯入／匯出，沒有多人連線。停用儲存仍可遊玩。

## 開發與建置

建議 Node.js 22.18+ 與 npm。使用鎖定檔可重現安裝。

```sh
npm ci
npm run dev
# http://127.0.0.1:5173
npm test
npm run build
npm run preview
```

`dist/` 是完整靜態網站，正式執行不需要 Node.js、資料庫或外部素材服務。也可執行 `python3 -m http.server 8080 --directory dist`。請透過 HTTP 開啟，不要雙擊 HTML。相對資源路徑支援子目錄部署。

## Docker / Nginx

```sh
docker compose up --build -d
# http://localhost:8080
docker compose down
```

也可把 `dist/` 放到任何靜態網站伺服器。參考 `docker/nginx.conf`；正式對外服務的 HTTPS 由部署端反向代理管理。

## v0.5 macOS App

Apple Silicon（M1 或更新）、macOS 12 以上。解壓縮發行 ZIP，將 `Red Banner.app` 拖到「應用程式」後開啟。遊戲與素材內建，可離線遊玩，不需要安裝 Node.js、Python 或啟動伺服器。

- 原生 macOS 匯入／匯出存檔視窗、全螢幕與原創旗幟圖示。
- 每 5 秒自動保存，離開視窗會暫停；退出前可按「保存並暫停」。重新啟動後按「載入紀錄」。
- 網頁版與 App 各自保存進度；透過 JSON 匯出／匯入搬移。v0.5.1 存檔記錄武將身份。可讀取 v0.4／v0.5.0 舊存檔並轉為關羽；新版存檔不能回匯到舊版。
- 本版為本機測試用 ad-hoc 簽署，尚未使用 Apple Developer ID 簽署及公證。從網路下載到其他 Mac 可能被 Gatekeeper 阻擋；正式對外發行需完成簽署／公證。
- Windows 封裝依使用者要求延後；Intel Mac 尚未建置驗證。

### 從原始碼建置 Mac 版

需要 Apple Silicon Mac、Xcode Command Line Tools、Rust stable、Node.js 22.18+。初次安裝套件需連網。

```sh
npm ci
npm run desktop:dev
npm run desktop:build:mac
cargo test --manifest-path src-tauri/Cargo.toml --release --target aarch64-apple-darwin
```

產物：`src-tauri/target/aarch64-apple-darwin/release/bundle/macos/Red Banner.app`。
共用 Web 核心；`src/desktop.ts` 只在 Tauri 內啟用原生操作，瀏覽器保留下載與檔案選擇功能。Rust 僅對使用者在對話框選定的檔案讀寫，不接收任意路徑。

## 原始碼

- `src/main.ts`：Phaser 場景、輸入事件緩衝、特效、HUD、最高分與操作介面。
- `src/combat.ts`：可獨立測試的戰鬥模擬、角色數值、AI、Boss 招式與波次。
- `src/actor.ts`：快取繪圖物件、12 fps 姿態動畫、三段刀光。
- `src/background.ts`：夕照關隘與月夜水寨兩套原創程序化像素場景。
- `src/save.ts`：版本化存檔、欄位驗證、戰鬥快照與載入。
- `src/levels.ts`：關卡、劇情、Boss 名稱與敵人編隊資料。
- `src/style.css`：街機外框、響應式版面與觸控操作。
- `tests/*.test.ts`：46 項規則與流程測試，包括正常輸入兩關通關模擬。

此版以程序化像素繪圖製作每秒 12 格姿態動畫，不使用外部圖像。後續可製作更細緻的原創精靈圖、音樂與更多關卡。

Node 測試執行器使用內建 TypeScript stripping，執行 `npm test` 建議 Node.js 22.18+。Web 正式輸出仍只需靜態 HTTP 伺服器。

## v0.3 關山夜渡

本版完整戰役為兩關、六陣、21 名敵人，最後完成評級結算。第一關「暮色關隘」保留鐵獄，第二關「夜渡蘆江」使用月夜、水面、渡船、蘆葦及木棧道場景。新 Boss 蒼鷲使用雙向橫掃、突進與震地，半血加速。橫掃可跳躍或閃身躲避。

- 每陣一只補給木箱，打破後掉落 +40 氣血藥包；擊倒重甲掉落 +25 藥包。
- 走近並落地自動拾取；滿血不消耗藥包，補血不超過上限。進入下一陣會清除上一陣未拾取補給。
- 前兩陣清場各回復 35 氣血；前往第二關時回復全血。
- 每次出征兩次續關：重新生成當前一陣敵人與補給，回復全血及短暫無敵；分數與擊倒數退回該陣開始時，最高連擊保留。
- 續關用完仍可用 R 或重開按鈕從第一關重新挑戰。續關是當次遊玩內的狀態，v0.4 起會自動保存，可重新整理後按「載入紀錄」接續。
- 通關評級：未續關且剩餘氣血至少 80 為 S；至多續關一次為 A；使用兩次為 B。最高得分保存在 `red-banner-best-v03`，與舊版記錄分開。

### 本機畫面驗證

`npm run dev` 時可使用 `?preview=river`、`?preview=intermission`、`?preview=continue`，分別預置第二關、轉場與續關畫面，方便測試。這些設定只在 Vite 開發模式生效，正式 build 會移除分支；正式網址無跳關功能。

## v1.0.1 穩定與平衡更新

戰鬥以每秒 60 次固定步進更新。10／20／30／60／144 FPS 的模擬結果一致；單幀最多補算 0.25 秒，避免長時間停頓後瞬間追趕。高刷新率下保留單次按鍵，補算時不重複觸發。暫停與切離視窗清除待處理輸入。過場改為五將通用敘述。存檔格式沿用 v0.5.1，v1.0 匯出的存檔可直接載入。詳見 RELEASE-v1.0.1.md。

## v1.1 操作與重玩

- 八個動作可在「設定／操作」重新配鍵（A–Z，R 保留重開）；衝突時提示，不覆寫另一個動作。方向鍵、空白、Enter、Esc 保留。設定保存在本機。
- 標準映射手把：左搖桿／十字鍵移動；第 0 鍵（A／×）攻擊與選單確認、第 1 鍵（B／○）跳躍、第 2 鍵（X／□）閃身、第 9 鍵 Start 暫停、第 8 鍵 Back 開關設定。選將用左右與 A。設定頁細項使用滑鼠／鍵盤，B 返回。不同裝置標示可能不同，未提供標準映射者不啟用。
- 手把斷線自動暫停，重新連接／返回視窗後須放開操作再繼續。死區為 0.25。
- 三個手動槽位位於設定頁，與原本自動存檔分開。覆寫既有槽位需點第二次確認。載入任一槽後保持暫停，可用原有匯出功能備份該進度。設定／按鍵／戰績不包含於單一遊戲存檔。
- 計分：基本傷害分加上連擊加成（每個先前命中增加 5%，最多 +100%）；每陣清場速度分 `max(0,1200-floor(本陣遊戲秒數)*10)`，本陣無傷 +800。暫停時間不計，命中停頓沿用遊戲時間規則。續關回退本陣分數並重設本陣挑戰。
- 新戰績以 v1.1 分開記錄，舊戰績資料保留在裝置中，不與新規則混榜。評級 S/A/B 規則沿用。
- 新存檔標記 1.1.0，讀取 0.4.0／0.5.1 格式。v1.0／v1.0.1 匯出的格式實際為 0.5.1。舊檔中途載入的當陣不發無傷獎勵，已清陣不補發；速度計時從載入點開始。舊版本無法讀取新版匯出的存檔。

詳細驗證及硬體限制見 RELEASE-v1.1.md。

從舊格式載入的整場戰役仍可玩與保存，但不列入 v1.1 新戰績；重新出征後即採用新規則排名。

## v1.2 視聽與戰場變化

五將各有五個對準實際命中時刻的攻擊姿勢：關羽大幅斬擊、張飛重矛下壓、趙雲前伸連刺、黃忠拉弓放弦、魏延貼身上挑。包含準備、蓄勢、接觸、延伸與收招；敵人擊倒後短暫傾倒淡出。這是原創程序繪製的動作強化，並未改變既有攻擊傷害或新增按鍵招式。

武器分別使用不同音高、波形、衰減與命中低頻聲；受既有音效音量／靜音設定控制。所有聲音在本機合成，無外部採樣素材。

前兩陣新增固定時序戰場事件，每 7 秒一輪，第 4 秒開始框線與進度條預警，1.4 秒後判定命中，扣 12 氣血。關隘箭雨會命中空中的角色，需走出框線或利用閃身無敵；江岸火線可跳躍（高度超過 38）、移開或閃身避開。每輪變換警戒行列；只有爆發瞬間判定一次，後續短暫圖案是效果殘留。敵兵不受己方支援火力影響。Boss 陣、清場後及暫停時不觸發。

戰場時間完整隨存檔保存，不在讀檔後重發已爆發的攻擊。v1.2 沿用雙關六陣與 21 名敵人，新增的是既有關卡的戰場機制，非第三關。新存檔格式標記 1.2.0，可讀取 1.1.0、0.5.1、0.4.0。舊檔可接續，但不列入 v1.2 新戰績，重新出征即可參與；舊資料仍保留。詳見 RELEASE-v1.2.md。

## 五將必殺技更新

五將各有獨立範圍、傷害與視覺效果的原創必殺。預設 I／手把 Y・△／觸控「必殺」，耗 12 氣血、冷卻 8 秒，需地面施放。設定頁可自訂按鍵，畫面顯示冷卻。完整規則、相容性與驗證見 SPECIAL-MOVES.md。
