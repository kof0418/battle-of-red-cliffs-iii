# 赤壁之戰三 · v1.3.1

原創三國街機橫向動作遊戲。Phaser 3 + TypeScript + Vite；960 × 540 像素畫面。五名武將、五關戰役、30 陣、185 名敵人。美術與音樂由程式原創製作，不使用《吞食天地 II》的受保護素材。

## 遊玩與操作

選擇關羽、張飛、趙雲、黃忠或魏延後按 Enter／出陣。WASD 或方向鍵移動；J 攻擊；K／空白鍵跳躍；L 閃身；P／Esc 暫停選單；R 要求返回選將（需確認）。支援標準手把、按鍵重設與觸控按鈕。

- 必殺技：先下、400 毫秒內按上，再於 280 毫秒內新按一次攻擊。無計量表、無獨立必殺鍵。五將各有專屬招式與武器撞擊音效，沒有戰吼或人聲配音。
- 抓取：停止攻擊，走近並推向敵人。抓住後可立即左右＋攻擊方向摔，或跳躍後在空中按攻擊空中摔；原地可打兩下再摔，第三次原地攻擊解除抓取。每次接招限時 2.8 秒；Boss 需半血以下且處於受擊硬直才可抓。
- 補給：打破木箱，走近藥包補血；滿血保留。每次出征兩次續關，從當前一陣重來。
- 暫停：遊玩時以遊戲畫面為主，設定收在暫停選單。切離視窗會暫停，回來後手動繼續。
- 無戰鬥存檔。重新整理、關閉頁面或返回選將需重新出征；音量、按鍵與通關戰績可保留。瀏覽器禁止儲存仍可遊玩。

## 五關戰役

| 關卡 | 場景 | Boss |
| --- | --- | --- |
| 1 | 暮色關隘 | 鐵獄・守關將軍 |
| 2 | 夜渡蘆江 | 蒼鷲・水寨統領 |
| 3 | 翠竹迷徑 | 玄弦・伏林弓將 |
| 4 | 霜嶺古堡 | 霜岳・破冰重將 |
| 5 | 赤焰宮城 | 炎驍・雙刃禁軍督 |

每關 5,600 像素、六個戰區。清場後前進，關卡結束按 Enter 繼續，第五關結束才完成戰役。兵種包含刀兵、快刀兵、盾兵、弓箭手、長槍兵及錘兵。前三個新增場景的配樂有 16 小節變化與 Boss 加速編曲。

## 開發與建置

使用 Node.js 22.18+ 與 npm：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
npm run release
```

`dist/` 為可獨立部署的靜態遊戲，不需後端或外部素材服務。可使用 `python3 -m http.server 8080 --directory dist`，或 Web 包內的 `python3 scripts/play.py`。請透過 HTTP 開啟，不要直接雙擊 HTML。

## Docker / Nginx

```sh
docker compose up --build -d
# http://localhost:8080
docker compose down
```

HTTPS 由部署端反向代理管理。設定見 `docker/nginx.conf`。

## macOS 架構

保留 Tauri 2 封裝，來源版本同步為 1.3.1；本次發行只驗證與發布 Web／原始碼，未重新建置 Mac App。舊 Mac 包不代表目前線上版本。

```sh
npm run desktop:dev
npm run desktop:build:mac
```

Mac 指令針對 Apple Silicon，需 Rust 與 macOS 開發工具。正式對外散布仍需處理簽署與公證。Windows 依使用者要求延後。
